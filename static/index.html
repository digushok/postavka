Точка отгрузки
Таймслот
Заявки создаются сразу без таймслота — как «Создать без таймслота» в кабинете. Слоты у Озона не запрашиваются; таймслот выберете потом в кабинете Озона.
После создания черновиков покажем свободные слоты — выберете один для всех городов. У кого его нет, возьмём ближайший.
Каждому городу — свободный слот в этот день, ближайший по времени. Если в этот день у города слотов нет — ближайший день.
