# Поставки Ozon

Программа для Windows, которая создаёт поставки FBO кросс-докингом в Ozon сразу во много городов:

- распределяет закупку по городам по долям;
- создаёт заявки: отдельно на каждый город или одну на все;
- ставит всем поставкам один таймслот;
- создаёт грузоместа (в каждой коробке один товар) и оформляет пропуск;
- собирает PDF с этикетками, отдельный файл на каждый одинаковый состав коробки.

Готовая программа для пользователей лежит в **[Releases](../../releases)**: архив с «Поставки Ozon.exe». Python для неё не нужен.

## Где хранятся данные пользователя

Ключи API, настройки, товары и партии хранятся в `%APPDATA%\Поставки Ozon\data` на компьютере пользователя.
В репозиторий они не попадают: папка `data/` указана в `.gitignore`.

## Выпуск новой версии

1. Внесите изменения в код.
2. В `version.py` увеличьте `VERSION`, обновите `RELEASE_DATE` и добавьте запись в начало `CHANGES`:
   - `1.4.0 → 1.4.1` — исправление ошибок;
   - `1.4.0 → 1.5.0` — новые возможности.
3. Обновите историю изменений: `python tools/release_notes.py --all > CHANGELOG.md`.
4. Закоммитьте изменения и поставьте метку версии:

       git commit -am "Версия 1.4.1"
       git tag v1.4.1
       git push && git push --tags

5. GitHub Actions за несколько минут:
   - соберёт .exe на Windows;
   - прогонит тесты;
   - проверит, что метка совпадает с `version.py`;
   - выложит архив в Releases.

   Программа у пользователей покажет внизу окна «доступна 1.4.1 — скачать».

Собрать .exe без выпуска можно так: Actions → «Сборка .exe» → Run workflow. Архив появится в артефактах сборки.

## Разработка

    pip install -r requirements.txt
    python app.py                         # откроется в браузере, http://127.0.0.1:8765
    python -m unittest discover -s tests

Для экспериментов без настоящего магазина: Настройки → «+ Демо-магазин». Запросы пойдут во встроенный демо-Озон (`mock_ozon.py`).

| Файл | Что внутри |
|---|---|
| `app.py` | локальный веб-сервер и API для интерфейса |
| `worker.py` | создание поставок в Озоне (черновики, заявки, грузоместа, этикетки, пропуск) |
| `planner.py` | распределение по городам и разбиение на коробки |
| `slots.py` | выбор таймслота |
| `ozon_api.py` | клиент Ozon Seller API (повторы, лимиты частоты, журнал) |
| `labels.py` | сборка PDF этикеток и листа сборки |
| `storage.py` | хранение настроек и партий, перенос из старых версий |
| `mock_ozon.py` | демо-Озон для проверки без магазина |
| `version.py` | номер версии и история изменений |
| `static/` | интерфейс (HTML, CSS, JS) |
