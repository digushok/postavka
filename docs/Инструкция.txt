ПОСТАВКИ OZON — как пользоваться

ЗАПУСК
1. Положите «Поставки Ozon.exe» в любое удобное место, например на Рабочий стол.
   Не запускайте программу прямо из архива — сначала распакуйте.
   Настройки, API-ключи, товары, партии и этикетки хранятся отдельно от программы,
   в папке %APPDATA%\Поставки Ozon (кнопка «Открыть папку» в Настройках → «Данные программы»).
   Поэтому .exe можно заменять новой версией и переносить — ничего не пропадёт.
2. Запустите «Поставки Ozon.exe». Программа откроется в браузере.
3. При первом запуске Windows может показать окно «Windows защитил ваш компьютер».
   Нажмите «Подробнее», затем «Выполнить в любом случае».
   Так бывает со всеми программами без цифровой подписи.
4. Чтобы закрыть программу, нажмите кнопку ⏻ в правом верхнем углу страницы.
   Если просто закрыть вкладку, программа продолжит работать в фоне.
   Повторный запуск .exe просто откроет её снова.

ПЕРВАЯ НАСТРОЙКА (вкладка «Настройки»)
- Client-Id и API-ключ из кабинета Ozon (Настройки → Seller API), затем «Проверить подключение».
  Ключу нужны роли для поставок FBO и чтение товаров.
- Точка отгрузки по умолчанию, данные водителя для пропуска, таймслот по умолчанию.
- Чтобы потренироваться без риска, нажмите «+ Демо-магазин»: в настоящий Ozon ничего не отправляется.

СОЗДАНИЕ ПОСТАВОК (вкладка «Новая поставка»)
1. Товары: SKU и количество (можно вставить из Excel). «В коробке, шт» — сколько штук в одном грузоместе.
   Готовое распределение можно загрузить целиком: «Импорт таблицы» → «Скачать шаблон» (Excel с вашими товарами
   и кластерами), заполните количество по кластерам и загрузите файл кнопкой «Выбрать файл…».
2. Распределение по кластерам — одна таблица: кластер Озона, доля и количество каждого SKU.
   Меняйте долю — пересчитается строка; меняйте количество — пересчитается доля
   (если по разным SKU доля разная, ячейки подсветятся). «+ Кластер» — добавить, «×» — убрать.
   Порядок кластеров — перетащите строку за ⠿ или стрелками ▲▼; он запоминается для магазина.
3. Грузоместа: группы одинаковых коробок — по ним будут файлы этикеток.
4. Отгрузка: точка, таймслот (желаемые день и время или выбор из списка), пропуск.
Нажмите «Создать поставки». 14 городов создаются около 15 минут:
Ozon разрешает создавать 2 поставки в минуту.

ЭТИКЕТКИ
Во вкладке «Партии» откройте партию:
- отдельный PDF на каждый одинаковый состав коробки;
- «Все этикетки» одним файлом;
- «Лист сборки».

КОПИЯ НАСТРОЕК И ПЕРЕНОС НА ДРУГОЙ КОМПЬЮТЕР
Настройки → «Данные программы»:
- «Сохранить копию настроек» — файл со всеми магазинами, ключами, точками, пропуском и товарами;
- «Загрузить из файла» — восстановить из такой копии (или перенести на другой компьютер);
- «Найти старые настройки на компьютере» — если настройки остались в папке старой версии.
Программа сама делает резервную копию настроек раз в день (папка backup).

ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
Ошибка по одному городу не мешает остальным. Нажмите «Продолжить» — программа доделает то, что не получилось.
Журнал запросов к Ozon — файл api.log в папке партии (кнопка «Открыть папку»).
